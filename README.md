# opencode-message-rail

OpenCode 2 TUI plugin: a right-edge message anchor rail with per-turn ticks, chevrons, a dwell-hover preview card and click-to-jump.

**Status: skeleton only, no logic yet.** Every function body is a `TODO` stub; only types, signatures and build config are in place.

## Commands

- `npm install`
- `npm run typecheck`
- `npm run build`
